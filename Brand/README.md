# Codex Deck identity

Three keys. One jump.

The mark uses two short keycaps and one full-height active key. The northeast arrow describes the app's central action: tap on iPhone, continue on Mac. The shape remains legible without lettering and works as an app icon or a small navigation mark.

- Ink: `#253a32`
- Paper: `#f5f2e8`
- Active key: `#c8e68a`
- Secondary key: `#8bb8bb`

`mark.svg` is the editable master. PNGs and the social card are rendered from original vector / HTML sources. Do not substitute OpenAI's logo: this is an independent project.

To regenerate: `npm install`, `npx playwright install chromium`, then `npm run brand` from the repository root. `CHROME_PATH` can select an existing Chrome executable. The site uses no external fonts, trackers or runtime packages.
