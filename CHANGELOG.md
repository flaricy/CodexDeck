# Changelog

## 1.0.1

First public release.

- A real keep-awake sun toggle with haptic feedback and persisted preference; iPhone only.
- Original three-key logo, shared iOS/Mac icon and bilingual product website.
- One-to-three-key adaptive session deck, desktop sidebar titles and persistent hiding.
- Local HTTPS pairing, QR scanner and a menu-bar Mac companion.
- Core Codex usage windows, foreground keep-awake and automatic reconnect.
- Read-only history adapter, UUID-restricted focus endpoint and regression tests.

Known limits: pending questions and approvals are not reliably detected; remote hosts and subagents are not supported. iPhone installation requires personal Xcode signing. The Mac download is not notarized and requires Python 3.10+.
