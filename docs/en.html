iPhone setup & signing guide ↗

Build and sign the iPhone app in Xcode with your own Apple ID. There is no App Store or TestFlight version yet. The Mac download is not notarized; see the install guide before opening it.

A few things to know.

Does Deck upload my sessions?

Deck sends session names, status and usage over local HTTPS, without a relay server. Pairing keys stay on your devices. Codex itself still connects to its services as usual.

Will it catch every pending question?

Not yet. Local Codex records do not provide a complete, reliable stream of pending questions and approvals. This version is not a question notifier. Status follows saved records; output silence is never treated as a stop.

Which sessions are supported?

Local main sessions from Codex desktop and extension sources are supported. SSH hosts and subagents are not included. A successful tap confirms that macOS accepted the session link.

Is this an official OpenAI product?

No. Codex Deck is an independent open-source project by flaricy. It is not affiliated with or endorsed by OpenAI.
